# 英雄防线：核心玩法

## 一句话概念

玩家在四条横向路线部署独特英雄，阻止敌人从右侧传送门推进到左侧能量核心；通过换线、升级与必杀技组合完成防守。

## 核心战斗循环

1. 选择 4–5 名英雄组成防守队伍。
2. 在路线部署英雄或支援装置。
3. 敌人沿路线从右向左推进。
4. 英雄自动攻击，玩家手动释放技能和调动英雄。
5. 击败一波敌人，获得能量与升级资源。
6. 通过最后一波 Boss，解锁下一关和长期强化。

## 战场规则

- 4 条平行路线。
- 每条路线 7 个部署位置。
- 左侧是能量核心，核心被摧毁即失败。
- 右侧是敌人传送门。
- 英雄可跨路线移动，但移动有冷却时间。
- 部署、换线和技能释放是玩家的主要决策。

## 二期需求：英雄接管

- 玩家可随时选择一名英雄进入“接管状态”，直接控制移动、普通攻击、闪避和主动技能。
- 被接管英雄可突破原有部署位限制，在当前路线及相邻路线之间短暂移动，但不进行无限制自由探索。
- 其他英雄继续自动战斗；接管期间可适度降低战场速度，保持塔防策略的可读性。
- 接管消耗能量或冷却，建议持续 6–10 秒；结束后英雄返回最近部署位或指定位置。
- 主要用途：处理 Boss、拦截漏怪、击杀关键单位、救援濒危路线，并展示角色的打斗与运动动画。
- 初期采用固定镜头 2D/2.5D 方案，不改变核心横向路线结构。
- 技术上使用 `Idle / Move / Attack / Skill / Hit / Dead` 状态；伤害在攻击动画关键帧触发。
- 二期先开放 1–2 名英雄和 1 个 Boss 进行验证，不纳入一期 MVP。

## 英雄定位

| 英雄类型 | 核心功能 |
|---|---|
| 剑盾 | 阻挡、护盾、保护后排 |
| 步枪 | 远距离单体输出 |
| 霰弹枪 | 近距离范围伤害与击退 |
| 火箭筒 | 大范围爆炸，冷却较长 |
| 双刀 | 快速换线、刺杀精英 |
| 大剑 | 横扫、眩晕、处理重型敌人 |

## 敌人设计

- 小型敌人：数量多、速度快，制造压力。
- 装甲敌人：移动慢、需要持续输出。
- 飞行敌人：绕过部分地面防线。
- 精英敌人：拥有护盾、冲刺或换线能力。
- Boss：改变路线、摧毁部署位或召唤援军。

## 关卡节奏

- 单局时长：3–6 分钟。
- 每关：8–10 波敌人。
- 第 4–5 波：精英敌人。
- 最后一波：Boss 或特殊机制。
- 关卡结束后：选择升级、解锁英雄或强化核心。

## 长期成长

- 英雄等级与技能升级。
- 武器分支：单体、范围、控制或暴击。
- 核心强化：生命、初始能量、路线修复速度。
- 地图解锁与敌人图鉴。
- 可选的轻度离线资源，不影响核心战斗公平性。

## 设计重点

- 英雄数量少但定位差异明显。
- 让换线和技能时机成为主要策略。
- 地图、敌人和技能保持高可读性。
- 使用原创世界观、敌人和 UI，避免直接复制其他塔防游戏的视觉元素。

## 独立开发 MVP

- 4 条路线、1 张地图。
- 4 名英雄：剑盾、步枪、霰弹枪、火箭筒。
- 5 种普通敌人、1 个 Boss。
- 10 个关卡。
- 部署、自动攻击、技能、升级和本地存档。
- 首先发布 Web 或桌面试玩版，再扩展移动端和更多地图。
